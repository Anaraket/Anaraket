### 👨‍💻 Кто я и чем занимаюсь:
Я из Белгорода, учусь в КВТ БГТУ им. В.Г. Шухова. Начинал с веба, но сейчас активно ушел в сторону **QA Automation**, **Linux-инфраструктуры** и бэкенда. Мне нравится писать скрипты, настраивать автоматизацию, ковырять терминал и делать так, чтобы сложные процессы работали по одной кнопке (или вообще без неё).
